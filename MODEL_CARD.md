# Model card: MASSIVE intent and slot extractor (LoRA on Qwen/Qwen2.5-1.5B-Instruct)

Generated by `python scripts/build_docs.py` from `docs/MODEL_CARD.template.md`. Every metric comes from a generated file under `results/`, together with its 95% confidence interval.

## Model

- **Base model:** `Qwen/Qwen2.5-1.5B-Instruct` at Hugging Face revision `989aa7980e4cf806f80c7fef2b1adb7bc71aa306`, license Apache-2.0.
- **Fine-tuning:** a LoRA Adapter on the bf16 base weights, with the base weights frozen. The Final_Configuration and its Validation F1 are in the sweep table below. The serving seed is 2.
- **Served form:** the Adapter is merged and quantized to GGUF Q4_K_M with llama.cpp `b11580`.
- **Weights:** the fine-tuned weights, the merged model and the Adapters are **not published**. They stay on the owner's machine until the owner decides otherwise.

## Intended use

Converting short English voice-assistant requests (alarms, music, weather, calendar, smart-home, lists and similar) into a JSON object with one intent and its slots, as the language-understanding step of an assistant prototype or demo.

## Out-of-scope uses

- Languages other than English. Only the English part of MASSIVE was used.
- Long documents, multi-turn dialogue, or requests far from MASSIVE's 60 intents and 55 slot types.
- Safety-critical or consequential decisions (medical, legal, financial, or controlling physical devices without confirmation). The model makes errors at the rates shown below.

## Data and splits

MASSIVE 1.1 English (`en-US.jsonl`), license CC BY 4.0. Its English text comes from SLURP, also CC BY 4.0. The official partitions are used as they are: 11514 Train examples (training), 2033 Validation examples (sweep and seed selection) and 2974 Test examples (every reported quality number). The splits are checked to share no example id.

## Limitations

- **Most common failure (error analysis):** of the 860 Test failures of the serving seed, 293 fall in the `wrong_intent` group; for example, "pink is all we need" was predicted as `{"intent": "play_music", "slots": [{"type": "music_genre", "value": "pink"}]}` against the gold `{"intent": "iot_hue_lightchange", "slots": [{"type": "color_type", "value": "pink"}]}`. The full breakdown:

| Failure group | Count |
| --- | --- |
| invalid_output | 0 |
| wrong_intent | 293 |
| missing_slot | 267 |
| extra_slot | 188 |
| wrong_slot_value | 112 |
| **Total analyzed** | 860 |

Every Test failure (F1 < 1) of the serving seed (2) is assigned to the first matching group.

Source `results/error_analysis.json`; command `python -m fts.eval`, seed `0`, commit `4e37f1be3ac2763570c4003ee343d59076f9be41`.

- Each system was measured with its own prompt: the fine-tuned model with a compact prompt, the baselines with label lists and exemplars.
- Quantization changes the scores slightly (see the F16 and Q4_K_M figures above), and the llama-server figures should be compared only with each other.
- Some Test utterances also appear in the Train_Split as identical text (MASSIVE's official partitions), so a small part of the Test score reflects memorized phrasings.
